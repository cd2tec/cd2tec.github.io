Plugin para Claude Code, Cowork, Codex e ChatGPT Work

cd2tec/archeo-harness-plugins

Plugins para o Archeo MCP Creator, que conecta bancos de dados legados a assistentes de IA. As mesmas skills, empacotadas para mais de um harness de agente, do banco legado ao painel executivo, com cada número conferido no seu banco.

  • spec-mcp-tool: transforma uma pergunta de negócio em uma ficha de ferramenta MCP. Explora o banco, escreve e testa o SQL e devolve a especificação pronta para o formulário.
  • build-mcp-dashboard: painel executivo de varejo a partir do ERP ou PDV, com KPIs, índice de saúde, rankings e curva ABC.
  • analyze-mcp-*: relatórios de estoque, vendas, compras, preços, perdas, fiscal, contábil e financeiro, cada um com conferência de reconciliação.
  • Só leitura: cada ferramenta é um SELECT fixo, parametrizado e validado pelo servidor. Nada é registrado automaticamente.
Apache 2.0 SQL Server PostgreSQL MySQL / MariaDB Oracle

CLI no npm · por Gabriel Fernandes

nayamonia/wrapper-code

Rode o harness do Claude Code com outros provedores de LLM sem tocar na sua configuração. Projeto pessoal de Gabriel Fernandes, fundador da CD2.

  • Um comando por provedor: deepseek, ollama, qwencloud, openrouter, kimi, zai-coding. O claude puro continua na Anthropic.
  • Escopo de sessão: nada é gravado em ~/.claude e nenhuma variável vaza para o seu shell. Sem gateway, sem processo em segundo plano.
  • Várias contas Claude lado a lado com --account e --temp, no macOS e no Linux.
  • Uso de tokens local: wrapper-code usage soma requisições e tokens por provedor e modelo, sem guardar prompts nem respostas.
MIT Node.js 18+ Anthropic Messages API README em EN · PT · ES

Terminal 
# instale uma vez
$ npm install -g wrapper-code

# veja os provedores e o status de cada um
$ wrapper-code list

# abra o Claude Code rodando no DeepSeek
$ wrapper-code deepseek

# ou num modelo local via Ollama
$ wrapper-code ollama

# quanto você usou, por modelo
$ wrapper-code usage
